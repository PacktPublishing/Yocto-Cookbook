<details open>
  <summary><h2>About the book</h2></summary>

  <a href="https://www.packtpub.com/en-us/product/yocto-cookbook-first-edition-9781807607531">
    <img src="https://content.packt.com/B38366/cover_image_small.jpg" alt="Yocto Cookbook, First Edition" height="256px" align="right">
  </a>

  Building embedded systems with the Yocto Project can dramatically cut development time, but production environments raise problems that introductory material rarely covers, including layer conflicts, image bloat, CI/CD integration, and security hardening. Yocto Project Cookbook skips the basics and goes straight to structured, task-oriented recipes for solving these concrete engineering problems.

  Each recipe addresses a specific challenge, from build optimization, layer design, and BSP customization to CI/CD integration, debugging, image optimization, security hardening, and long-term maintenance. Every solution explains not just how to implement it, but the reasoning behind the design decisions and trade-offs involved.

  Written by Marta Rybczyńska, a network security specialist with 20 years of open source experience and a member of the Yocto Project security team, this book reflects how Yocto Project is actually used in professional embedded Linux projects, giving you a reference to return to throughout active development rather than just a conceptual overview.

</details>

<details open>
  <summary><h2>Key Learnings</h2></summary>

  <ul>
    <li>Modify existing recipes and create new ones for your own hardware</li>
    <li>Organize and reuse recipes across layers for maintainable builds</li>
    <li>Build custom Yocto Project distributions using proven best practices</li>
    <li>Set up embedded CI and collaborate effectively as a team</li>
    <li>Contribute recipes and fixes back to the Yocto Project community</li>
    <li>Keep dependencies current through a structured update process</li>
    <li>Optimize images for smaller size and easier long-term maintenance</li>
  </ul>

<details>
  <summary><h2>Get to know the author</h2></summary>

  *Marta Rybczyńska* is a network security specialist with 20 years of experience in open source and 15 years in embedded Linux development, working across the full embedded software stack. She is the founder of Ygreky, an open source security company focused on advancing the security of embedded systems, with core expertise in Linux kernel internals and building robust, regulation-ready platforms.

  Marta is a member of the security team of the Yocto Project, a member of the OpenEmbedded Technical Steering Committee, and co-maintainer of the meta-security layer, giving her a firsthand view of how Yocto Project is used and maintained in production.
